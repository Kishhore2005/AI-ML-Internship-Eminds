`# 🎬 Movie Recommendation System

A sophisticated movie recommendation application built with **LangGraph** and **Streamlit**, powered by **Groq LLM** and the **Unofficial IMDb API**. This system provides personalized movie suggestions based on user-specified genres with real movie data fetched via IMDb IDs.

---

## 🌟 Features

- **Real Movie Data**: Powered by an IMDb-based API with real-world titles
- **Genre-based Recommendations**: Get suggestions across 18+ genres
- **AI-Enhanced Responses**: Groq LLM offers personalized movie recommendations
- **Interactive UI**: Built with Streamlit for a seamless user experience
- **LangGraph Workflow**: Structured conversation and recommendation flow
- **Memory System**: Remembers your previous preferences and inputs
- **Offline Fallback**: Uses mock data when the IMDb API is unavailable

---

## 🎭 Supported Genres

- Action, Comedy, Drama, Horror, Romance, Sci-Fi, Thriller, Adventure, Animation, Crime, Documentary, Family, Fantasy, History, Music, Mystery, War, Western

---

### Prerequisites

- No IMDb API key needed — uses a public endpoint
